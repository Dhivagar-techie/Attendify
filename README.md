# Attendify — HR Attendance Management Dashboard

Attendify is a modern and responsive HR Admin Dashboard designed for employee attendance tracking, payroll monitoring, roster management, and workforce analytics.

The application features a dynamic real-time calendar, attendance overview charts, employee management system, responsive layouts, notes management, and dark mode support.

---

# Features

## Dynamic Real-Time Calendar

* Automatically detects current month and year
* Dynamically generates monthly days
* Today highlighting
* Attendance status indicators
* Future dates fully accessible

## Attendance Management

* Mark Present / Late / Absent
* Update attendance records
* View daily attendance breakdown
* Employee-wise attendance tracking
* Monthly attendance analytics

## Employee Management

* Add new employees
* Edit employee information
* Department categorization
* Salary tracking
* Employee roster overview

## Payroll Insights

* Daily salary calculation
* Attendance-based payroll summary
* Present/Absent employee analytics

## Responsive Dashboard UI

* Desktop, Tablet, and Mobile responsive layouts
* Mobile sidebar overlay
* Responsive notes panel
* Adaptive grids and cards

## Interactive UI Features

* Glassmorphism design
* Dark mode support
* Animated dashboard components
* Attendance analytics chart
* Notes management panel
